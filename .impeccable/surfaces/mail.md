# Terminal Mail web client

Mode: Operate. Scope: authentication, linking, the mail client, settings, and phone PWA. Audience: invited mailbox owners using keyboard or pointer, with MCP agents alongside them.

## Direction contract

THESIS: Port the approved Terminal Mail specification exactly. Three tiled windows divide folders, conversations, and reading; no new visual direction is needed.

OWN-WORLD: Paper #E6E6E1, graphite #4A4A46, Silkscreen display, IBM Plex Mono chrome, Plex Sans reading, Doto numerals. Crisp 9×9 bitmap icons, 1.5px frames, active-title racing stripes, QuickDraw patterns, crop marks, barcode progress. Self-host fonts.

STORY: Sign in, link iCloud using an app password, then read, write, search, and organize real mail. Agent activity and sync status describe actual state.

FIRST VIEWPORT: At 1440×900, 6px gutters, a 232px sidebar, 444px list, remaining-width reader, and 26px status bar. Auth uses the reference's crop-mark headline and separate 420px form window. Mobile uses the specified single pane and bottom tabs.

FORM: User-selected reference, artifact version 3; seed: none (unavailable). Signature interaction: pane collapse to graphite spines and reader maximize. Stepped window and toast motion, respecting reduced motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
